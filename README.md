# Away mode: a Ziki prototype

HNG 15, week 5, Task 1 (human–agent interaction on Ziki). By Odofin Moronke, Team Cybertron.

This is a mockup, not the real Ziki, and all the data is pretend. It builds on Ziki's existing Inbox, My agents and Activity & Approvals pages. It adds:

- away hours
- rules for each agent by level (contributor, reviewer, triager)
- a stale-claim warning
- a short "while you were away" summary
- trust checks

It's one static page (`index.html`). There's no build step.
